Operational tips

  • Vertical resolution of 300 still gives the most realistic results for the current model tuning.
  • Larger horizontal resolutions allow stronger converging winds and longer-lived organized convection.
  • Performance is mostly GPU dependent; a GTX 1070-class GPU or better is recommended for real-time play.
  • If you have a laptop with a dedicated GPU, make sure the browser is actually using it.
  • Fullscreen mode (F11) gives the best cockpit and storm-viewing experience.

Simulation controls

Mouse

  • Middle mouse button drags the simulation area.
  • Mouse wheel zooms, or changes brush size while holding B.
  • Left mouse button uses the selected tool. Hold Ctrl (Command on macOS) for the inverted action.
  • Touchscreen input is still basic and mainly intended for experimentation.
